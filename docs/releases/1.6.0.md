## Lineboard 1.6.0

基于 Tendedero 的非官方通用剪贴板扩展，发布名称与图标独立，不代表上游作者。源码保留原 MIT 版权声明。

### 下载与安装

| 文件 | 用途 |
| --- | --- |
| `Lineboard-1.6.0-universal.dmg` | 推荐：打开后把 Lineboard 拖入「应用程序」 |
| `Lineboard-1.6.0-universal.app.zip` | 解压后直接获得 `.app` |
| `SHA256SUMS.txt` | 下载文件的 SHA-256 校验值 |
| `build-info.json` | 源码提交、架构、系统要求与签名状态 |

支持 **macOS 14+，Apple Silicon 与 Intel**。更新前退出旧的 Tendedero/Lineboard，关闭旧版的开机启动，避免两份同时监听。配置和历史记录沿用原 Bundle ID；无需清理数据。

本包为 **ad-hoc 签名，未经 Apple 公证**，不含 Developer ID。首次打开可能被系统拦截；确认来源可信后，可在「系统设置 → 隐私与安全性」使用系统提供的「仍要打开」。不需要关闭 Gatekeeper 或 SIP。

### 本版功能

- 自动收集文字、图片、Finder 文件和文件夹，多选文件独立成卡；文字拖出为纯文本。
- 文件引用、Quick Look 预览、扩展名标签＋单行省略文件名；文件拖出默认复制，移除卡片保留原文件。
- 宋体文字便签、底部内容渐隐、两端渐隐横线；文件卡片使用系统字体，字号可配置。
- 三种简约金属夹、深浅色主题适配，修复删除时夹子闪回默认款。
- 左上角悬停触发、多桌面状态恢复、图标设置菜单归组；相同文字去重。

### 已知限制

文件保存为引用，源文件移动或删除后会失效；预览取决于系统对格式的支持。部分网页不接收文本拖放。便签内部仍以明文文件存储。全屏显示默认关闭，可在图标菜单中开启。构建成功不代表所有桌面环境下的效果均已验证。

### 从源码构建

```bash
git clone -b feature/universal-clipboard https://github.com/LeeHero0803/tendedero.git
cd tendedero
scripts/package-release.sh 1.6.0
```

需要 macOS 与 Swift 开发工具链；建议使用完整 Xcode。输出位于 `build/release/`，不运行测试脚本。GitHub 自动提供的 `Source code` 压缩包是源码，不是可安装应用。
